## 为什么保留这些值

本轮只整理作品集，不根据单局成绩调参。历史 R1 玄武正式局最低 Qi0、最终 Qi16，192/713 个周期快照低于 Dash 费用；这说明该自动策略遇到短缺，不证明所有玩家体验良好，也不能把快照占比当真人缺气率。

三功法当前版本的广泛平衡、无文字可读性、风雷协同与首次体验仍待测试。历史“问题 → 假设 → 修改 → 结果”见 [策划案例](PortfolioCaseStudy.md)与[归档 Playtest](Archive/Playtest-before-portfolio.md)，不将旧调参重新包装为本轮工作。
