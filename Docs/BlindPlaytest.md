## 测试安排

使用 T07 Formal 360 秒 Build，默认音效开启，记录版本指纹、耳机/音箱、分辨率。首次试炼不指定功法，让玩家自己读菜单。计划每人 10～15 分钟：首次尝试、重试一次、结束访谈。不要在过程中提示正确路线；可以记下玩家的原话。玩家同意后再录屏，避免采集无关个人信息。

给测试者的唯一开场说明：

> WASD 移动，鼠标控制镜头，Shift 使用 Dash，Q 使用 Shield。现在请自行开始体验。

观察者不要提前解释 Qi、四种天劫、散花安全夹角、胜利条件和功法优劣。游戏内自然出现的 HUD 与首次天劫名称属于被测试的教学内容。暂停/退出问题可提供操作帮助，并记为一次帮助。

## 结束后中性提问

1. 用自己的话描述刚才发生了什么，以及你如何决定去哪里。
2. 哪一次受伤最意外？当时看见或听见了什么？
3. 哪个技能帮到了你？有没有想用但没有用出来的时刻？
4. 为什么选这个功法？重试时想换吗？
5. 哪个阶段想继续尝试，哪个阶段想跳过？
