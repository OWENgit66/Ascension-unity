# 当前版本真人盲测

**状态：pending，独立真人盲测样本为 3。** 

## 使用版本与说明

测试 **当前去文字版本、Formal 180 秒**。先核对 [ReleaseChecklist](ReleaseChecklist.md) 的构建和指纹状态，未验证的新包不要与旧包混用；Fast 90 秒仅用于开发，不替代本轮首次体验。

首次尝试只告知：

> WASD 移动，鼠标控制镜头；Shift 使用 Dash，Q 使用 Shield。请自行开始体验。

不要提前解释 Qi、各种危险、散花夹角或功法优劣。允许玩家阅读游戏内现有菜单和提示。记录任何额外帮助；如需录屏，先取得测试者同意，不采集无关个人信息。

建议安排一次首次尝试、一次自主重试及简短访谈。记录 Build 指纹、功法、设备、分辨率和游戏经验，避免用不同版本的体验直接比较。


## 真人盲测结果与首轮反馈

测试状态：已完成首轮小规模真人盲测。  
样本量：3 人。  
测试对象：均为首次接触《渡劫 Ascension》的同学。  
测试目的：观察首次体验中的玩法理解、操作感受、内容完整度与视听反馈。

> 注意：本轮样本量较小，主要用于发现问题，不用于计算通关率、满意度或得出具有统计意义的结论。

---

### Tester A

**首次体验反馈：**

> “这就没了吗？”

**观察与初步判断：**

测试者完成体验后，对游戏结束产生了明显的“内容已经结束了吗”的反应。

当前无法仅根据这一句话判断具体原因，可能涉及：

- 单局结束反馈不足；
- 通关后的成果感较弱；
- 玩家期望还有后续内容；
- 三分钟体验结束较突然。

由于本轮没有进一步追问 Tester A，因此暂时不将该反馈解释为“游戏时长过短”或“玩法内容不足”。

**后续验证方向：**

下一轮测试重点询问：

- 是否觉得游戏过程本身太短；
- 是否只是通关结算缺乏反馈；
- 如果继续游玩，玩家期待的是新机制、难度还是单纯更完整的结束表现。

---

### Tester B

**首次体验反馈：**

> “画面太粗糙了，音乐也不咋地。”

**观察与初步判断：**

Tester B 的负面反馈主要集中在表现层，而不是操作或核心玩法。

当前可以确定的初步问题包括：

- 整体视觉完成度较低；
- 场景、角色、特效或 UI 之间可能缺少统一的视觉风格；
- BGM 的质量、风格匹配度或循环体验未达到玩家预期。

本轮未进一步区分“音乐选择不合适”“音量/混音问题”或“音乐重复度高”，因此暂不对具体音频问题作进一步结论。

**后续验证方向：**

优先检查：

- 主界面、HUD、结算界面的视觉完成度；
- 危险特效、角色和背景之间的风格一致性；
- BGM 是否符合修仙 / 渡劫题材；
- BGM 音量、循环点及与战斗音效之间的混音关系。

---

### Tester C

**首次体验反馈：**

> “操作还挺流畅的。”

**观察与初步判断：**

Tester C 对基础移动与操作响应给出了正面评价。

这说明在该测试者的首次体验中：

- WASD 移动没有出现明显阻塞；
- 基础输入响应未成为主要负面体验；
- 当前操作系统暂时不属于首轮需要优先修改的问题。

该反馈仅代表单个测试者的主观体验，不能据此认定操作体验已经完成验证。

## 首轮结论

本轮 3 名首次玩家没有形成足够样本支持玩法平衡、通关率或机制理解方面的普遍结论。

目前最明确的反馈集中在：

1. **游戏结束感与内容完整度可能不足。**
   Tester A 在体验结束后表示“这就没了吗？”，说明当前通关后的反馈或内容预期存在进一步验证价值。

2. **视听表现是当前最明显的完成度短板。**
   Tester B 明确指出画面粗糙、音乐体验较弱，因此下一轮优化优先级应高于继续增加新玩法系统。

3. **基础操作暂未暴露明显问题。**
   Tester C 对操作流畅度给出正面反馈，因此当前不优先调整基础移动与输入逻辑。

现阶段不建议因为少量反馈继续扩展新天劫、功法、装备或剧情系统。

下一轮优先级为：

**视觉表现 / 音乐与结算反馈 → 再次真人测试 → 核心玩法理解与死因观察 → 最后决定是否调整玩法内容。**

## 本轮测试限制

本轮测试存在以下限制：

- 样本量仅 3 人；
- 未对所有测试者执行统一的测试后访谈；
- 未完整记录存活时间、功法、Dash / Shield 使用次数等行为数据；
- 部分反馈为体验结束后的自然评价，没有进行结构化追问；
- 因此本轮更适合作为形成性测试，用于发现问题，而不适合用于证明游戏体验已经改善。

后续测试应采用统一记录方式，至少记录：

- 测试者首次选择的功法；
- 是否持续绕圈；
- 是否主动使用 Dash / Shield；
- 是否主动冒险拾取 Qi；
- 第一次明显困惑的位置；
- 最终死亡 / 通关原因；
- 测试结束后的 3–5 个固定问题。
