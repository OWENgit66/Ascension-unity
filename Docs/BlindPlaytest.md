## 使用版本与说明

测试 **当前去文字版本、Formal 180 秒**。先核对 [ReleaseChecklist](ReleaseChecklist.md) 的构建和指纹状态，未验证的新包不要与旧包混用；Fast 90 秒仅用于开发，不替代本轮首次体验。

首次尝试只告知：

> WASD 移动，鼠标控制镜头；Shift 使用 Dash，Q 使用 Shield。请自行开始体验。

不要提前解释 Qi、各种危险、散花夹角或功法优劣。允许玩家阅读游戏内现有菜单和提示。记录任何额外帮助；如需录屏，先取得测试者同意，不采集无关个人信息。

建议安排一次首次尝试、一次自主重试及简短访谈。记录 Build 指纹、功法、设备、分辨率和游戏经验，避免用不同版本的体验直接比较。
