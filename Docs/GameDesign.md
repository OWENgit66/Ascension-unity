# 当前玩法规格

版本：V1.1 R1 + 常规雷击去文字调整。2026-10-07 核对源码；本轮 Portfolio Polish 不改玩法。历史规格见 [Archive](Archive/README.md)。

## 定位与循环

Windows 单人小型修仙生存竞技场。观察预警 → 选路线 → 步行/Dash/Shield → 取气与留预算 → 四阶段存活。不是以主动击杀敌人为核心的战斗游戏；没有 NPC、剧情、装备、背包或开放世界。

## 阶段

| 阶段 | 正式 / Fast 秒数 | 主要任务 |
| --- | --- | --- |
| 第一重 | 35 / 10 | 认识普通预警、低频随机雷和 Qi |
| 第二重 | 40 / 12 | 连环、预测和封路；水火组合、1 个雷球 |
| 第三重 | 45 / 14 | 追踪、风雷、区域压力与 2 个雷球 |
| 终劫 | 60 / 54 | 编排组合与九道神雷，最多 3 个雷球 |

合计 Formal 180 秒 / Fast 90 秒。共用模型，Fast 覆盖阶段时长，终劫 cue 按时长归一化；技能、伤害和区域寿命仍使用既有规则，不把短局视作正式局等价平衡实验。

## 预警与伤害

- 常规普通、随机、连环、预测、追踪、封路和神雷不再绘制每枚雷的名称、倒计时和黑色文字框，也不显示最近落雷 HUD 倒计时。
- 地面图形仍保留。圆环线宽随预警进度增强；普通/随机/连环/预测/封路/神雷通常预警 1.3 秒，风雷配对 1.2 秒。
- 追踪雷前 0.9 秒跟随，随后锁点静止 0.5 秒，1.4 秒攻击；预测雷根据当前速度外推后固定，不继续追踪。
- 视觉冲击、声音与伤害沿用落雷事件；图形范围使用规则半径。特殊天劫名称和机制文字、阶段提示、HP/Qi/剩余时间/技能 HUD 保留。
- 不承诺所有屏外攻击都能在当前镜头内看见；去文字之后是否更易理解仍待真人测试。

## 危险的不同任务

| 危险 | 当前行为与反制 |
| --- | --- |
| 普通 / 随机雷 | 固定落点圆圈；随机雷合法圆内抽点，不专门瞄准玩家，忙时退让 |
| 连环 / 预测 / 追踪 | 连续出现、速度预测或延迟锁点；观察时机、变向、必要时 Dash |
| 封路雷 | 前方三点短墙与持续电场，要求改线；不是围住玩家的闭环 |
| 风劫 | 有方向的位移压力，0 伤害；Shield 不抗推，Dash 可修正位置 |
| 火劫 | 多个持续伤害区域，退出并等待结束；重叠不按每区叠伤 |
| 地劫 | 线段裂缝与碎岩，横向离开路径 |
| 散花雷 | 中心爆点后放射雷带，避中心、选安全夹角 |
| 水劫 | 0 伤害，步行变为 70%，重叠不叠加、离开恢复；Dash 不被减速，Shield 不净化 |
| 球形闪电 | 有限寿命的路点移动威胁，最多 3 个；接触伤害有共同冷却 |

当前风雷配对先同时预警，雷在 1.2 秒结算，风在 1.5 秒开始推动；不能描述成同一枚配对雷在风推后才爆发。

## 资源与功法

Dash 与 Shield 共用 Qi。补给位于中央或偏离当前路线的位置，合法性检查避开明显危险；部分普通雷后有风险掉落，随机背景雷不额外掉 Qi。具体上限、恢复、费用和冷却见 [Balance](Balance.md)。

青云：低费短冷却 Dash，盾更贵。玄武：盾便宜且厚，Dash 更贵。九霄：拾取收益更高，盾更短。三者复用同一套技能逻辑，不增加第四种功法。

## 公平性约束

限制危险数量与主要家族数；背景随机雷为重要组合让位。生成/锁定时检查有限方向步行路径，区域组合也采样安全面积并计入风推与水减速。它是保守的准入筛选，不是全局可达性证明，更不能代替真人可读性验证。

## 流程与范围

存活至计时结束为胜利；HP 归零失败，同帧伤害优先。暂停冻结玩法推进。Restart 清空危险、重置 HP/Qi、阶段、技能状态和配方历史，保留所选功法。输入与构建见 [README](../README.md) 和 [BuildGuide](BuildGuide.md)。
