# 渡劫 / Ascension — 设计 v0.1

## 定位与范围
Windows 单机、第三人称 3D 修仙生存 Vertical Slice，目标单局 6 分钟。用于策划面试：重点展示可读的危险、资源机会成本、难度教学与依据实测修订数值的过程。采用 Unity 2022.3.62f3（本机安装），仓库验证基线为 2022.3.62f3c1；兼容性须通过构建验证。

用户设定：筑基修士在山顶渡劫台抵御天劫，成功晋升金丹。无额外剧情、NPC、装备、背包和开放世界。新增设计提案：落雷结束后部分危险地点留下灵气，让玩家有理由返回刚刚躲开的区域。

## 核心体验与循环
读预警 → 选择步行规避或消耗灵气 → 等待雷击结算 → 抢收灵气 → 为下一轮保留余量 → 推进雷劫 → 突破。

玩家唯一胜利目标为活过最终雷劫；HP 为零立即失败。局内不回血，HP 是整局失误预算；Qi 是可以补充的短期应急预算。步行可应对单个普通雷，任何时刻 Qi 为零都不能自动形成必死局。

## 输入与规则
- WASD：相机相对移动；鼠标：第三人称环绕镜头。角色朝向移动方向。
- Shift：按下触发御剑冲刺，固定消耗，有冷却与短暂无敌；方向取当前移动方向，无输入时向角色前方。
- Q：按下触发定时护盾，有总吸收量上限及冷却。期间仍能移动；不与Dash自动组合消费。
- Esc：暂停/恢复并释放/捕获鼠标；开始、失败与成功菜单均可重来。
- 圆台限制移动位置；边界清晰，第一版不增加坠落惩罚。

## 雷劫的决策与公平性
普通雷：生成时锁定位置，圆环由空到满，预警结束后一次判定；离开圈边需要计入角色碰撞半径。

连环雷：三次依次采样玩家位置，每次独立拥有完整预警，不在结算瞬间凭空补击。危险数量设上限，避免随机重叠封死全部路径。

追踪雷：先跟随玩家，随后明确锁定并停止移动，锁定后留出步行或Dash反应窗口。追踪/锁定不仅用颜色区分，也改变环形符号与文字。

同一短时间内多道命中使用受击保护，避免一次失误被瞬间清空HP。阶段变化不缩短已生成预警的剩余时间。死亡与胜利同帧时优先结算伤害，避免死者晋升。

## Qi 与风险收益
初始Qi支持数次应急，收集是持续使用技能的主要来源。C2提高补给供给，同时将额外灵气置于刚结束落雷的位置。追逐当前收益可能把玩家带入下一轮危险；等待又可能损失收集窗口。C3降低供应以检验资源储备，但保留安全刷新，防止消耗后不可恢复。

数值及供需估算见 Balance.md。所有数值均为待实测假设，不能把纸面预算当成已验证平衡。

## T07 功法三选一（当前实现）

开局/结算时选择，局中及暂停时不能切换；Restart保留选择并重新赋值，禁止叠加。保留同一Balance和Mechanic，不复制阶段或伤害逻辑。

- 青云剑诀：Dash 14Qi / 2s，Shield 36Qi / 45吸收 / 2s，拾取20Qi。偏向改变路线，紧急护盾需要更多储备。
- 玄武真诀：Dash 24Qi / 2.5s，Shield 24Qi / 60吸收 / 2s，拾取20Qi。便宜护盾换更昂贵的撤离。
- 九霄心法：Dash 18Qi / 2.5s，Shield 30Qi / 45吸收 / 1.5s，拾取25Qi。主动补给收益更高，护盾时机更严格。

此前文档中的距离加成、减速、受伤回Qi为未实现草案，现替换为费用/容量/拾取取舍：T06.5已显示风与护盾的边界，不在这一轮引入受伤刷Qi或改变移动安全检查假设。HP、速度、Dash距离、全部危害数值、阶段与Director规则保持原值。

## T06.5：复合天劫（实现中）

有效可移动半径R来自Balance.arenaRadius与模型ClampMagnitude，当前16米。保持Mechanic/Presentation分层；在原TribulationModel的partial文件内扩展规则，不创建第二套玩法模型。

Final A（0–18秒）：风→火→地→散花各自介绍。Final B（18–34秒）：风+火、地裂+落雷、散花+火；Final C（34–58秒）：九道神雷与风/火/地之一组合。通过预设配方控制频率，替代完全随机权重；首轮刻意不用35/20/15/15/15随机抽签，避免首次教学缺项或同局强度偏差。Director检查在场系统、家族冷却、上次配方、玩家位置与未来推力路径；同时最多两类主要系统。

散花雷：中心20伤害、6条地面雷带18伤害；中心和雷带属于同一事件，每事件最多一次伤害，避开交叉瞬杀。雷带提前画出，中心爆炸后0.25秒生效，观察60度夹角避让。
风：显示地面箭头，预警后连续推移；仍能移动，Dash期间不受风推，Shield不免风。位置最终Clamp在R内。
火：持续区域控制，跨火区共用0.5秒伤害节拍，每跳5，防止重叠重复结算；经过边缘只需承受小量伤害。
地：以线段距离检测裂缝宽度，1条短线不闭合成圈，每事件只结算一次25伤害。

所有新伤害进入现有Shield/HP流程；最后伤害来源显示在HUD和死亡页面。新形状不遮盖其他预警；不做地形破坏或大量粒子。安全检查保留至少55%采样面积和一条含风推预测的普通步行路线，不宣称数学上穷尽所有组合。
