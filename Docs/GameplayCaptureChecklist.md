## 更高质量人工录制清单

- [ ] 使用 [ReleaseChecklist](ReleaseChecklist.md) 对应的当前 EXE，记录版本/功法/模式；不打开旧360秒 Build。
- [ ] 保留 HUD，录制15–30秒、至少720p的视频；展示圈出现→改线避让→拾取青色Qi。
- [ ] 包含一次 Dash 和一次 Shield，能看出 Qi 支付和技能状态；不要只拍静态界面。
- [ ] 加入至少一种终劫：风向、持续火区、水区、裂缝、散花安全夹角或球形闪电。
- [ ] 若需要跨阶段剪辑，明确标注剪辑，不把不同片段拼成虚假的连续操作。
- [ ] 普通雷不应有“落雷/随机雷/预警0.X”即时文字框；阶段与特殊机制文字可保留。
- [ ] 检查普通音量、画面裁切、鼠标遮挡、中文字体和可读性；视频建议放 Release，README 使用小GIF或预览图链接。
- [ ] 替换 `Screenshots/portfolio-20261007-gameplay.gif` 或更新 README 路径，写明新素材的 Build 来源、操作者与模式。

不要使用AI生成游戏画面，也不要把自动输入称为真人操作。
