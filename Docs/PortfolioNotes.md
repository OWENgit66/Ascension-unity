# 当前面试展示提纲

当前：正式180秒、Fast90秒，常规雷击依靠地面图形预警。历史六分钟提纲见 [Archive](Archive/PortfolioNotes-before-portfolio.md)。

## 推荐讲述顺序

1. 30秒介绍渡劫生存循环和个人/AI分工。
2. 播放当前真实实机片段；未录制前只展示明确标记版本的截图。
3. 讲固定绕圈为什么让技能失去价值，以及预测、封路和风险补给的判断。
4. 展示注明版本的策略对照，说明自动输入不是人类通关率。
5. 说明自测反馈如何推动局长与去文字调整，并承认独立盲测还没有结果。

## 可以安全讲的主线

我定义目标、范围和验收，用 Codex 辅助实现和测试。早期固定绕圈能解决过多危险，因此要求改变路线任务与补给成本，而不只提高伤害。三功法保留机动、防御和恢复的取舍；步行精确躲避仍可能通关。后续根据自测调整三分钟节奏和预警呈现，最新去文字修改不动数值。

## 不应越过的边界

- 没有独立真人盲测结果，不能说理解率、留存或满意度提升。
- AI 辅助代码、Debug、自动测试和文档，不称本人手写全部源码。
- GameFactory Runtime、第三方模型/音效和 AI 背景明确署名。
- 原生自动策略可读取状态；高 HP 模型覆盖只查规则，不能当生存成绩。
- 每个结果按 [Playtest](Playtest.md) 的版本归属描述，不拿旧 Build 冒充新源码。
